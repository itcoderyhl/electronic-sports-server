## 【原创】SpringBoot3+Vue3前后端分离的电竞赛事网站

## 系统介绍

基于SpringBoot3+Vue3前后端分离的电竞赛事网站，系统包含管理员、用户角色，功能如下：
- 管理员：首页统计（数据统计、性别饼状图、战队饼状图、帖子饼状图、7天发帖折线图）；用户管理；游戏管理；战队管理；选手管理；选手评价；赛事管理；竞技交流（版块分类、帖子管理、评论管理）；竞技新闻；系统留言；公告信息；修改个人资料；修改密码。
- 用户：登录、注册；战队信息（游戏分类、战队列表、详情、收藏、战队成员）；选手信息（游戏分类、选手信息、详情、关注、评价）；赛事信息；竞技交流（版块、帖子、详情、点赞、评论）；电竞新闻；系统留言；系统公告。用户还具有个人中心功能，功能包括：战队收藏、选手关注、选手评价、我的帖子、帖子评论、帖子点赞、系统留言、个人资料、密码修改。
系统界面美观大方，功能丰富，使用了SpringBoot3、Vue3、Element-Plus、Echarts等技术栈。

项目由本人原创开发，经过多次测试，项目运行无问题，请放心使用，作者QQ：1344127185。

## 使用技术

服务器端技术栈：

- Springboot3
- SpringMvc
- Mybatis
- MySQL

前端技术栈：

- vue3
- element-plus
- axios
- echarts

## 环境介绍

- IDEA集成环境
- JDK17+
- MySQL8.0+

可提供所有运行软件、远程安装、技术指导。
